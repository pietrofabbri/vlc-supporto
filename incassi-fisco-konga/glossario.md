# Glossario

| Termine | Significato |
|---|---|
| **Art. 74** | Regime IVA speciale (monofase) dei libri: l'IVA al 4% la paga l'editore una volta sul prezzo di copertina |
| **Forfettizzazione delle rese** | IVA sulle copie consegnate, abbattute del 70% per i libri |
| **Copie vendute** | Metodo alternativo: IVA solo sulle copie effettivamente vendute |
| **Corrispettivi** | Incassi da vendite a privati senza fattura; si annotano e, salvo esoneri, si trasmettono |
| **Registratore telematico** | Cassa che memorizza e invia ogni giorno i corrispettivi all'Agenzia |
| **SDI** | Sistema di Interscambio dell'Agenzia delle Entrate per le fatture elettroniche |
| **Intermediario SDI** | Servizio che invia e riceve le fatture per conto vostro (per Konga, quello collegato al modulo Legal Solution) |
| **TD01 · TD04 · TD17** | Tipi di documento elettronico: fattura · nota di credito · integrazione/autofattura per servizi dall'estero |
| **Natura N4** | Codice per operazioni esenti (es. servizi finanziari come le commissioni di Stripe) |
| **Reverse charge** | L'acquirente italiano applica l'IVA al posto del fornitore estero (a debito e a credito) |
| **Split payment** | Per le fatture alla PA: l'ente versa l'IVA direttamente all'Erario, il fornitore incassa solo l'imponibile |
| **CIG** | Codice identificativo di gara, obbligatorio nelle fatture e nei pagamenti della PA |
| **Codice univoco ufficio** | Codice di 6 caratteri che identifica l'ufficio PA destinatario della fattura |
| **MePA** | Mercato elettronico della pubblica amministrazione |
| **OSS** | Sportello unico UE per versare l'IVA dovuta in altri Paesi per vendite a privati |
| **PSP** | Fornitore di servizi di pagamento: Stripe, PayPal, Satispay, SumUp… |
| **Payout** | Versamento del saldo dal PSP alla banca: un bonifico per molte vendite, al netto delle commissioni |
| **Conto transitorio** | Conto contabile "ponte" in cui passano vendite e commissioni prima del payout |
| **Riconciliazione** | Abbinare ogni movimento in banca alle vendite o fatture che contiene |
| **Chiave API ristretta** | Chiave Stripe con permessi limitati (es. sola lettura), da usare negli script |
| **Webhook** | Avviso automatico che un servizio manda a un altro quando succede qualcosa |
| **PCI DSS** | Standard di sicurezza per i dati delle carte; con le pagine di pagamento ospitate si è al livello minimo |
| **SDD · RiBa** | Addebito diretto SEPA · Ricevuta bancaria |
| **kongalib** | Libreria Python ufficiale di EasyByte per leggere e scrivere nel database Konga |
