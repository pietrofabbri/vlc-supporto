# Profilo azienda

| Campo | Valore |
|-------|--------|
| Forma giuridica | Ditta individuale, contabilità ordinaria |
| Persone | 1–2 (Konga usato da 2–3 persone) |
| Fatturato | Meno di 100.000 € → **microimpresa** (esente EAA per i servizi) |
| Sede | Ferrara, Emilia-Romagna; laboratorio aperto al pubblico, in affitto |
| Clienti | Soprattutto aziende ed enti (B2B e PA via MePA); privati sul sito |
| Cosa vende | Libri cartacei (tutti con ISBN), servizi di stampa e rilegatura, cartoleria e oggetti, prodotti personalizzati; e-book in valutazione |
| Paesi | Solo Italia |

## Canali
| Canale | Stato |
|--------|-------|
| Sito proprio | WooCommerce, attivo, importante; 0–50 ordini/mese |
| Negozio / laboratorio | Sì |
| Librerie | Vendita diretta, marginale; nessun distributore |
| Marketplace | **Da chiarire** (risposte discordanti) |
| PA | MePA abilitato |

## Strumenti
| Area | Strumento |
|------|-----------|
| E-commerce | WooCommerce (WordPress), backup automatici |
| Pagamenti | Stripe, POS bancario, bonifico, contanti |
| Spedizioni | Un corriere + Poste + ritiro in sede |
| Email | Gmail (non dominio aziendale), nessuna newsletter |
| Analytics | Google Analytics / Meta Pixel installati, **senza banner cookie** |
| Gestionale | Konga Lite + fattura elettronica e conservazione, assistenza EasyByte |
| AI | Nessuno strumento |

## Applicabilità dei moduli
| Modulo | Si applica? |
|--------|-------------|
| Recesso e pulsante di recesso | ✅ |
| Prezzi e promozioni (Omnibus) | ✅ (niente sconti barrati né recensioni oggi) |
| GDPR e cookie | ✅ — priorità |
| Accessibilità EAA | ❌ esente come microimpresa (consigliata) |
| GPSR sicurezza prodotti | ✅ (anche per i libri) |
| Green claims | ✅ (claim sul sito) |
| Imballaggi PPWR | ❓ da verificare con il commercialista (riuso imballaggi) |
| IVA OSS | ❌ nessuna vendita UE |
| AI Act art. 50 | ❌ nessun uso di AI |
