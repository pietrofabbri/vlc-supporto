# Checklist lancio / restyling

## 4–6 settimane prima
- [ ] Profilo azienda compilato — [profilo](../02-azienda/profilo.md)
- [ ] Piattaforma scelta con i criteri di [architettura](../05-sito-web/01-architettura-piattaforma.md)
- [ ] Catalogo completo nel formato dati di [catalogo](../06-commerce/01-catalogo-schede-prodotto.md)
- [ ] Testi legali pronti — [pagine legali](../05-sito-web/06-pagine-legali-obbligatorie.md)
- [ ] Gateway pagamenti attivati e testati — [pagamenti](../06-commerce/03-pagamenti.md)
- [ ] Contratti corrieri e regole di spedizione — [spedizioni](../06-commerce/04-spedizioni-resi.md)
- [ ] Piano di redirect 301 dalle vecchie URL (se restyling)

## 1–2 settimane prima (su staging)
- [ ] Ordini di prova con ogni metodo di pagamento, rimborso e recesso
- [ ] Test da mobile reale (iOS e Android), connessione lenta
- [ ] Core Web Vitals di laboratorio in verde su home, categoria, prodotto — [performance](../05-sito-web/02-performance-core-web-vitals.md)
- [ ] Test accessibilità: tastiera, lettore di schermo, contrasti — [EAA](../03-normativa/04-accessibilita-eaa.md)
- [ ] CMP configurata: nessun tag di marketing prima del consenso
- [ ] Dati strutturati validati — [SEO](../05-sito-web/03-seo-e-ricerca-ai.md)
- [ ] Email transazionali (conferma, spedizione, recesso) con dominio autenticato SPF/DKIM/DMARC — [email](../06-commerce/06-email-marketing-crm.md)
- [ ] Sicurezza: 2FA admin, backup, aggiornamenti — [sicurezza](../05-sito-web/05-sicurezza-tecnica.md)
- [ ] Checklist conformità legale completata — [legale](checklist-conformita-legale.md)

## Giorno del lancio
- [ ] Rimuovere blocchi di indicizzazione (noindex/password)
- [ ] Sitemap inviata a Search Console e Bing
- [ ] Feed Merchant Center attivo
- [ ] Analytics e conversioni verificate (con e senza consenso)
- [ ] Monitoraggio uptime attivo

## Prime 4 settimane
- [ ] Controllo giornaliero ordini, errori di pagamento, 404
- [ ] Search Console: errori di indicizzazione
- [ ] Prime recensioni richieste ai clienti
- [ ] Revisione delle domande al customer care → aggiornare FAQ e schede
